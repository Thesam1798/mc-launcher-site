mc-launcher

Launcher de bureau pour un serveur Minecraft Java moddé. Desktop launcher for a modded Minecraft Java server.

{{icon:triangle-alert}}

Aucune version n'est distribuée et le serveur n'est pas ouvert. Ce site documente un projet en cours.

No build is distributed and the server is not open. This page documents work in progress.

{{icon:boxes}} À quoi il sert What it is for

Le serveur tourne en 1.21.1 avec NeoForge. Un client doit charger exactement le même jeu de mods que le serveur, sinon la connexion est refusée pour désynchronisation des registres.

Installer NeoForge, copier les fichiers dans le bon dossier, puis recommencer à chaque mise à jour : c'est là que la plupart des joueurs abandonnent. Le launcher fait ces étapes à leur place, garde le jeu de mods à jour et ouvre la connexion au serveur.

The server runs Minecraft 1.21.1 with NeoForge. A client must load exactly the same mod set as the server, otherwise the connection is refused because the registries no longer match.

Installing NeoForge, copying files into the right folder, then doing it again on every update is where most players give up. The launcher does those steps for them, keeps the mod set current and connects them to the server.

{{icon:key-round}} Connexion au compte Signing in

Le launcher n'a pas de système de comptes. Il ne stocke ni ne voit aucun mot de passe. Le joueur s'identifie chez Microsoft avec le flux OAuth 2.0 device code : il saisit un code sur une page Microsoft, s'authentifie normalement, MFA comprise, et le launcher ne reçoit qu'un jeton.

The launcher has no account system of its own. It never sees or stores a password. The player signs in with Microsoft through the OAuth 2.0 device code flow: they enter a code on a Microsoft page, authenticate as usual including MFA, and the launcher only ever receives a token.

Aucun contrôle de sécurité, d'authentification ou de licence n'est contourné, et aucune fonction de sécurité n'est désactivée. Le launcher n'utilise pas de secret client, et aucun identifiant de joueur ne transite par notre infrastructure.

No security, authentication or licence check is bypassed, and no safety feature is disabled. The launcher uses no client secret, and no player credential ever passes through our infrastructure.
